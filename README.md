A Unity-based interactive 3D scene designed to explore player controls, object interaction, and basic game mechanics.

## 🧾 Project Overview

This project was created as part of my practice in Unity player controls, interaction systems, and object management.  

In this scene:
- Animals move toward the player  
- The player can choose to **feed or shoot** them  
- Animals disappear after interaction  

This project helped strengthen my understanding of:
- Object lifecycle management  
- Input handling  
- Player–environment interactions  

---

## 🎯 Project Goals

- Learn **player input scripting** (shoot/feed mechanics)  
- Implement **collision-based destruction** of game objects  
- Experiment with **choice-based interactions**  
- Gain experience with **prefabs and object lifecycle management**  

---

## ⚙️ Technical Details

- **Game Engine:** Unity (2022.3.44f1)  
- **Hardware/Input:** PC (Keyboard input system)  

---

## 🧠 Unity Skills Applied

- **Scene Navigation**  
  - Spatial movement using Unity fly mode  

- **Game Object Navigation**  
  - Creating and aligning objects in the scene  

- **Programming**  
  - Object spawning and destruction  
  - Input system handling  
  - Interaction logic  

---

## 👨‍💻 My Role

- Designed and set up the environment (terrain, animals, player)  
- Implemented player controls (look, aim, shoot, interact)  
- Scripted animal behaviors (approach, react to actions)  
- Programmed object destruction upon hit detection  
- Used prefabs for reusable and consistent behaviors
